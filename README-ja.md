# 🐦 Chirp English

[English](README.md) | **日本語**

## このプロジェクトについて

Chirp Englishは、架空のSNSを眺めるような感覚で、気軽に英語を読むための無料Webアプリです。短い英文や返信、架空の街の住人たちの日常や物語を、自分のペースで楽しめます。

**住人・都市・施設・団体・ニュース・天気・事件・SNS投稿などはすべて架空です。** 実際のSNSには接続していません。リアルタイムのAI会話生成も行いません。

## 主な機能

- **Easy / Normal**の2段階の英語フィード、短い投稿とリプライ
- 🌐ボタンで表示する日本語訳、投稿と返信の独立した既読記録
- 住人のプロフィール、DM、選択式の自分の投稿、時間差で届く返信
- Stories、架空のニュース・天気・季節・時間帯の投稿
- **Continue reading**、**Reading history**、保存した投稿の一覧
- ユーザー表示名・アイコン・背景色、7つのFlower Themes
- 文字サイズ設定（標準・＋2px・＋4px）、一度に表示する投稿数（3〜7件、初期値4件）
- JSONファイルでのデータ追加・更新、ローカル保存とバックアップの書き出し・読み込み

## 使い方とデータ

配布ZIP内のHTML・JSONなどのファイルをすべて同じフォルダーに配置し、GitHub Pagesなどで公開できます。[日本語の使い方ガイド](guide.html)もご利用ください。初回アクセスの方にはガイドを読むかどうかを一度だけ尋ねます。既存のセーブデータがある場合は案内を表示しません。

進行状況はブラウザーのローカルストレージに保存されます。設定の「Export save data」で定期的にバックアップしてください。端末のデータ消去などで記録が失われる場合があります。「Import save data」で復元できます。保存キーは従来どおり `chirp-english-v3` を使っています。以前の保存ファイル `chirp-save.json` もインポートできます。
