# 🐦 Chirp English

[English](README.md) | **日本語**

*架空のSNSを眺めるように、気軽に英語を読むためのアプリです。*

## このプロジェクトについて

Chirp Englishは、個人で制作している無料の英語学習Webアプリです。架空の住人による短いポストや返信、街のローカルニュース、続きものの物語を読んで楽しめます。**実際のSNSではありません。** アカウント、会話、都市、お店、天気、出来事はすべて架空です。返信は事前に用意されたもの、または端末内でシミュレーションされるもので、AIがリアルタイムに生成するわけではありません。実在の利用者からメッセージが届くこともありません。

## 主な機能

- EasyとNormalの2つの読書モード。日本語訳は必要に応じて表示。
- 住人のプロフィール、用意された返信スレッド、DM、ストーリー、架空のニュース・天気・イベント・時間帯の投稿。
- 選択式の自分の投稿とシミュレーション返信。対象の新規投稿には約1時間後の追加返信もあります。
- Reading history、Continue reading、ブックマーク、既読状況の保存。
- 起動時は閉じているMy Posts。開くと3件ずつ表示。
- 投稿に登場した表現を検索できるLittle English Lab（[Labを開く](lab.html)）。
- 自分の表示名、絵文字アイコン、アイコン背景色、7種類のFlower Themes、文字サイズ設定。
- Feedの読み込み件数（3〜7件、初期値4件）と、選択ポスト一覧の日本語訳表示切り替え。
- 端末内セーブデータの書き出し・読み込み。投稿やストーリーなどの制作済みデータはJSONファイルで提供。

## 使い方と更新方法

Chirp EnglishはGitHub Pagesなどで公開できる静的Webサイトです。利用者が動かすためにNode.jsサーバーは必要ありません。Ver.4.7.3のZIPに入っている**全14ファイル**を、ファイル名と相対位置を変えずにまとめて配置してください。アプリ内から[日本語ガイド](guide.html)も開けます。新しい利用者には初回だけガイドの案内が表示されます。

更新する前に、**Settings → Export save data** で必ずバックアップを取ることをおすすめします。必要なら **Import save data** で復元してください。既読履歴、自分の投稿、プロフィール設定などは、ブラウザーのlocalStorageに従来のキー `chirp-english-v3` で保存されます。サイトデータを消去したり、ブラウザー・端末を変えたりすると、記録が失われる場合があります。過去のセーブファイルや投稿・返信IDとの互換性を維持する設計です。ブラウザーのキャッシュやGitHub Pagesの公開処理により、更新がすぐ反映されないこともあります。

- 起動時のMy Postsは**閉じた状態**です。**元の投稿日時の新しい順**に表示し、返信が増えても並び替えません。

### Ver.4.7.1 — 安定化と読みやすさ

- My Postsは初回**3件**、以後3件ずつ追加。関連する返信が画面に約1.4秒見えたら既読情報を保存します。
- Feedの読み込み件数には、再登場する返信スレッド・ストーリー・日常ポストも含めます。読み込み件数を変更しても既に表示中の投稿は消しません。
- すべての選択ポスト候補に日本語訳を用意し、Settingsから表示・非表示を切り替えられます（初期値は表示）。
- 対象の新規選択ポストには約1時間後にシミュレーション返信が1件追加されます。次回起動時にも反映されますが、プッシュ通知は送信しません。古い保存済み投稿には追加されません。
- 6つのアイコン候補を🐿️ 🧁 🍮 🎀 💎 🎵に入れ替え、既に選んだ旧アイコンは維持できるようにしました。
- 新ストーリーが「LOCAL LIFE」と表示される問題を修正し、Normal・Easy・ストーリーの返信修正版を取り込みました。
- JSONの構造・ID・文字列長などの基本的なデータ検証を追加しました。あらゆる攻撃への安全性を保証するものではありません。
- セーブデータのキーやIDはそのままです。更新前のバックアップをおすすめします。

## プライバシーと安全性

Chirp Englishではアカウント登録は不要で、独自のサーバー上のユーザープロフィールデータベースも運用していません。進行状況や選択した投稿はブラウザー内に保存されます。実際のメッセージサービスではなく、現実のプッシュ通知も送りません。GitHub Pagesなどの公開サービスでは、通常のアクセスログが処理される場合があります。ブラウザーやサイトのデータを消去すると保存情報が失われる可能性があるため、更新前にバックアップしてください。架空のニュース、天気、交通情報、地名などは**現実の情報として使わないでください**。基本的なデータ検証は実装していますが、網羅的なセキュリティ監査を受けたという意味ではありません。
