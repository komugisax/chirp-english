# 🐦 Chirp English

A fictional social media feed for casual English reading practice.

## About This Project

Chirp English is a small, personal English-learning experiment inspired by social media timelines.

All users, posts, and conversations are fictional and created for language-learning purposes.

There are no real users, real conversations, or live social media connections.

## Features

- Short, casual English posts
- Fictional characters and reply threads
- Japanese translations available on demand
- Bookmarks and reading progress tracking
- A collection of posts that can be expanded over time

## Privacy

This app does not require an account or collect personal information through a registration system.

Bookmarks and reading progress are stored locally in your browser.

## Disclaimer

This is a personal hobby project, not an official social media service. Any resemblance to real people or events is coincidental.

## 🤖 AI-Assisted Project

Chirp English is a personal English-learning project created with the assistance of ChatGPT (OpenAI).

The concept, features, and creative direction are guided by a human, while AI is used to help develop the application and generate fictional content.

All characters, posts, and conversations are fictional. They do not represent real people or actual social media activity.

This project is an independent hobby project and is not affiliated with OpenAI or any social media platform.
